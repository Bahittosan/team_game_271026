# Педагогикалық миссия — Vercel (исправление 404)

Это статическая игра на казахском языке. Не нужны React, npm, сборка и внешние библиотеки.

## Структура

```
vercel.json
public/
  index.html
  favicon.svg
  favicon.ico
```

## Публикация через GitHub + Vercel

1. Распакуйте ZIP и поместите **содержимое** архива в корень репозитория (не загружайте ZIP как один файл).
2. В Vercel импортируйте этот репозиторий.
3. Убедитесь, что **Root Directory** указывает на каталог с `vercel.json` и папкой `public`.
4. Framework Preset: **Other**. Build Command: не задавайте.
5. Output Directory: **public**. Он также зафиксирован в `vercel.json`.
6. Нажмите **Deploy**; при обновлении существующего проекта сделайте новый деплой после загрузки новых файлов.

## Ошибки консоли

* Если сама игра работает, но браузер сообщал 404 только для favicon, теперь в `public` добавлены оба формата иконки.
* Сообщение `content.js: No Listener: tabs:outgoing.message.ready` не генерируется игровым кодом. Попробуйте открыть сайт в инкогнито без расширений.
* Если 404 вместо самой игры, проверьте Deployments → нужный деплой → Source / Output: там должен быть `index.html`. Проверьте **Root Directory** и **Output Directory**.
* Если ошибка останется, пришлите адрес Vercel-сайта и полный URL ресурса, возвращающего 404, из вкладки Network.
